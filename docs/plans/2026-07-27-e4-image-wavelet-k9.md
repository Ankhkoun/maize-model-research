# E4：严格纯影像 K9 Mexican-hat 小波编码

## 目标

在 E3 的严格纯影像设定上，只将局部 Mexican-hat 小波的支持范围由 K5（\u00b12 帧）扩展为 K9（\u00b14 帧）。不使用 DOY、日历位置编码或可学习的时间槽位编码。

## 固定对照

- 实验 ID：`E4-ImageWPE-K9`
- 时间位置编码：`kind: none`
- 小波：内容驱动 Mexican-hat，三尺度，`kernel_radius: 4`
- 感受野：9 帧，约 56 天（8 天合成序列）
- 除小波支持范围外，训练设置与 E3 保持一致。

## 执行步骤

1. 为可配置 K9 偏移量写失败单元测试。
2. 将现有 K5 实现泛化为可选半径，默认仍为 2，保证 K5 行为不变。
3. 添加 E4 冻结配置与训练配置守卫，并完成模型路由测试。
4. 运行目标测试、完整测试集、编译检查与 diff 检查；提交可复现实验代码。
5. 启动 E4 正式训练；训练完成后进行独立 Validation 回放。Test 集评估另行确认。
