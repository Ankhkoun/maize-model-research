# 训练流程与公式对应

两版共用 AgriFM＋FPN、无损失 GMM 的 D 教师及双时序专家。普通 CE 预热 3 轮，D 教师 12 轮，双时序专家拟合 30 轮，学生继续训练 12 轮。AgriFM 始终冻结，教师训练更新 FPN 和条件噪声矩阵，专家拟合更新光谱模板与尺度，学生训练仅更新 FPN。教师和学生均按 Dev mIoU 选择，学生候选包含第 0 轮教师。

本文以 \(\tilde y_i\) 表示二元弱标签的 one-hot 向量，\(p_i^T\) 表示冻结教师概率，\(p_i^M\) 表示时序专家的类别后验。标签 255 对应的位置不进入训练损失。代码部分函数保存玉米类标量概率，另一类概率为其补数。

## 1. D 教师的邻域联合似然

三个共享条件噪声专家的转移矩阵为

\[
T_k=\begin{bmatrix}1-\alpha_k&\alpha_k\\\beta_k&1-\beta_k\end{bmatrix},\qquad
T_{iv}=\sum_{k=1}^{3}w_{ivk}T_k.
\]

矩阵行表示潜在真实类别，列表示观测弱标签。代码对每个专家的三个原始参数做 softmax，取前两项为 \(\alpha_k,\beta_k\)。路由权重根据直接观测比例、最长缺测及三段季节覆盖条件的标准化距离计算。

\[
w_{ivk}=\operatorname{softmax}_k\left(-\|z_{iv}-\mu_k\|^2/5\right).
\]

中心与两个跨区域近邻构成 \(G_i\)。忽略缺失的近邻弱标签后，联合损失为

\[
L_D=-\frac{1}{|\mathcal V|}\sum_{i\in\mathcal V}
\log\sum_{c=0}^{1}p_\theta(c\mid X_i)
\prod_{v\in G_i}T_{iv}[c,\tilde y_v].
\]

此阶段所有有效中心等权。代码使用 log-softmax、对数求和及 logsumexp 实现数值稳定的联合似然。

对应 `models/noise.py` 的 `Noise.matrices`、`Noise.forward`、`conditions`、`routing`，以及 `training/teacher.py` 的 `joint`、`train`。

## 2. 两版专家拟合监督

\[
a_i=\lambda\tilde y_i+(1-\lambda)p_i^T,
\qquad \lambda\in\{0,0.25\}.
\]

系数 0 版直接拟合教师软概率。系数 0.25 版加入固定比例弱标签。两版使用同一个无 GMM 的 D 教师，教师和软锚点在专家拟合时固定。

对应 `models/temporal_moe.py` 的 `soft_target` 与 `training/experts.py` 的 `prepare`。

## 3. 日历专家与时间对齐专家

只对直接实测的时相和波段计算高斯光谱对数密度。每类 3 个模板，光谱尺度在两专家及全部类别模板间共享。

\[
\ell_{ecr\delta}(i)=\sum_{t,b}m_{it}
\log\mathcal N\!\left(x_{itb};\mu_{ecrb}(d_t-\delta),\sigma_b^2\right).
\]

日历专家使用 \(\delta=0\)。时间对齐专家对位移集合 \(\{-14,-7,0,7,14\}\) 天边缘化，先验为 \((1,2,3,2,1)/9\)。位移模板通过线性插值获取，两端日期使用边界值。

\[
\mathcal L_{\mathrm{cal}}(i,c)=\log\frac{1}{3}\sum_{r=1}^{3}\exp\ell_{\mathrm{cal},cr,0}(i),
\]
\[
\mathcal L_{\mathrm{align}}(i,c)=\log\frac{1}{3}\sum_{r=1}^{3}\sum_\delta
\rho_\delta\exp\ell_{\mathrm{align},cr\delta}(i).
\]

两个专家先验 \(\pi_e=0.5\)。专家拟合损失为

\[
L_{\mathrm{fit}}=-\frac{1}{N}\sum_i\sum_c a_i(c)
\log\sum_e\pi_e\exp\mathcal L_e(i,c).
\]

类别先验 \(\eta_c\) 为训练有效像元软锚点的平均值。后验计算为

\[
p_i^M(c)=\frac{\eta_c\sum_e\pi_e\exp\mathcal L_e(i,c)}
{\sum_{c'}\eta_{c'}\sum_e\pi_e\exp\mathcal L_e(i,c')}.
\]

路由权重为 \(P(e\mid x_i)\)，根据观测证据计算，随后对专家的类别后验加权。

对应 `models/temporal_moe.py` 的 `Evidence`，以及 `training/experts.py` 的 `fit_experts`、`evidence_tile`。

这里去除的是根据分类损失拟合的可靠性 GMM。双时序专家保留了原实验中的高斯光谱似然和多模板混合。

## 4. 学生软目标与交叉熵

\[
t_i=\lambda\tilde y_i+(1-\lambda)\hat p_i,
\qquad
\hat p_i=\begin{cases}p_i^M,&\text{存在直接实测时相},\\p_i^T,&\text{无直接实测时相}.\end{cases}
\]

\[
L_{\mathrm{student}}=-\frac{1}{|\mathcal V|}\sum_{i\in\mathcal V}\sum_c
\operatorname{stopgrad}(t_i(c))\log p_\theta(c\mid X_i).
\]

学生从教师 FPN 初始化，固定软目标，继续训练 12 轮。训练中不额外乘可靠性权重。最终影像推理使用冻结 AgriFM 与选中的 FPN。

对应 `training/experts.py` 的 `generate_targets`、`models/temporal_moe.py` 的 `soft_target`、`soft_ce` 以及 `training/student.py` 的 `train`。
