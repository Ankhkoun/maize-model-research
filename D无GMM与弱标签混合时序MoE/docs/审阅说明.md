# 审阅说明

本包对应两项已完成历史实验，原始D＋MoE去损失GMM版和固定0.25弱标签混合版B_moe。作者本次明确要求整理为可审阅代码包。整理沿用此前D＋GMM＋双时序MoE独立代码包的模块结构，改为等权D损失、固定混合监督，并保留两版配置。

## 方法对应

共同流程为官方冻结AgriFM＋新FPN普通CE3、D教师12轮、专家30轮、学生12轮。教师原型包含中心与两个跨区域近邻、三个条件噪声矩阵。两版的监督差别集中在专家软锚点和学生软目标，系数0为原直接教师/专家概率，系数0.25为弱标签混合。共享teacher_run_dir由配置明确指定。

专家的Gaussian光谱密度、每类3模板、两专家先验0.5、位移[-14,-7,0,7,14]及先验[1,2,3,2,1]/9、直接观测掩膜及无观测回退均保留。原固定邻域检索与归一化、BF16分类器训练、有效标签范围、固定0.5评估协议保留。

## 历史来源

原版目录为usa_calendar_aligned_no_gmm_fullflow_20261030，B版目录为usa_gmm_simplification_20261103/arms/B_moe。归档教师SHA为92b819d38f14d897b304d4acadb8552f948bea97091528212f18ef87c168e782。正式历史运行复用已经核验的共同CE3和无GMM D教师，专家和学生重新拟合。此包提供从数据到教师再到两版学生的完整训练入口。

provenance/original_sources.json记录原脚本、训练记录与结果文件的哈希。results保留历史逐轮和完整分类指标，代码整理本身只作CPU验证，GPU全流程复现留待目标环境执行。新配置生成的权重使用本包源码/配置指纹，历史原检查点的整阶段恢复需使用原归档代码和对应来源锁。
