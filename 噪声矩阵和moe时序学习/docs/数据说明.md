# 数据接口

模型的全部 Python 实现都在本项目内。外部需要提供影像、弱标签、协议划分、归一化统计、Dev 参考标签、Test 原生参考栅格及官方预训练权重。

## 配置与目录

编辑 `configs/usa_seed42.json` 的 `paths`。这些路径均可指向实际数据位置；配置中的相对路径以该 JSON 所在目录为起点。

```text
data/
  protocol/
    train_validation500.csv
    gtdev60.csv
    test500.csv
    normalization_train1296.json
  cubes/<sample_id>/
    x_cube.npy
    source_map.npy
    metadata.json
    time_quality.json
  pseudo_labels/<sample_id>/
    pseudo_label.npy
    metadata.json
  dev_labels_30m/<sample_id>/y_patch_30m.npy
  dev_labels_10m/<sample_id>/y_patch.npy
  reference/2021_30m_cdls.tif
weights/AgriFM.pth
```

`dev_labels_30m` 是优先来源；没有对应 30m 文件时，才从 `dev_labels_10m` 聚合。不是两份数据同时参与监督。

## 数组与元数据

| 文件 | 接口 |
|---|---|
| `x_cube.npy` | float32，`26×10×256×256`，有限值；与原训练数据相同的反射率单位 |
| `source_map.npy` | `26×256×256`；编码在 1、2、3、4 内；1 为直接观测，其余不进入时序专家观测似然 |
| `pseudo_label.npy` | `256×256`；0 非玉米，1 玉米，255 忽略 |
| 影像 `metadata.json` | `sample_id`、`crs="EPSG:3857"`、`band_names`、GDAL/Affine 顺序的 `transform` 前 6 项 |
| 弱标签 `metadata.json` | `mode="vvp_mmi_intersection"`，`mmi_method="otsu"`；用于确认原始弱标签来源 |
| `time_quality.json` | 26 条记录，`slot_id` 依次为 t01 至 t26；`path` 若有日期后缀，须与 2021 年 4 月 1 日开始的周窗口一致 |
| `normalization_train1296.json` | `train_count=1296`，`mean` 和 `std` 各含 10 个波段值 |

波段顺序固定：B2、B3、B4、B5、B6、B7、B8、B8A、B11、B12。编码器使用代码内保留的官方归一化常量；时序专家使用 Train 的归一化统计，并在读取时将非直接观测位置清零且屏蔽。

## 划分与监督边界

CSV 必须提供 `sample_id`、`region_id`。`train_validation500.csv` 还要有 `split`；只使用其中 `split=train` 的 1,296 条。`gtdev60.csv` 有 60 条，且与 Train 无交集。`test500.csv` 有 500 条。

Train 使用原始弱标签，不读取 Train 真值。Dev 参考只用于评估与选模；专家拟合不使用 Dev 标签。Test 只在完成学生训练、Dev 选模并执行 `seal` 后评估。

固定协议：Dev 使用 Derived85；Test 使用 Native30m-v1 的重投影平均与全局首次出现去重，阈值 0.5，参考有效像元 1,959,211。代码中的划分、统计和参考数据 SHA256 用于保持历史评估口径。若更换数据集或划分，应另建实验协议，而不是只改哈希以继续称为该历史实验。

## 邻域与缺测

每个影像块提取冻结 F1，将 1024 维特征固定投影到 64 维，以余弦相似度检索。候选来自 Train 每块固定 `8×8` 锚点。两个近邻来自两个不同的其他区域；每对需要至少 6 个共同直接观测时相，并且前中后三段都有共同观测。检索结果按 `4×4` 输出像元共享。

近邻标签 255 在联合似然中被边缘化；中心标签 255 不进入训练。跨区域相似性和共用潜在类别是建模假设，不代表已知真值。

GMM 样本为 `2×2` patch：至少 3 个有效弱标签、类别纯度至少 0.75，且存在直接观测支持。每块每伪类别单独拟合；少于 32 个合格 patch、无方差或拟合退化时不可用。教师训练用单位损失权重；冻结教师后生成锚点和软目标时 q=1，保留原弱标签。

## 输出

```text
outputs/usa_seed42/
  teacher/
    prepared/       # CE3、Train 近邻与来源记录
    checkpoints/    # 12 轮教师权重、Dev 历史与最优轮次
  student/
    prepared/       # 固定教师概率与 q、专家拟合、软标签
    checkpoints/    # 12 轮学生权重与 Dev 最优轮次
    outputs/seal.json
    test/          # 封存后的 Native30m-v1 结果
```

本项目不包含数据制作、集群调度或远程上传脚本。正式运行前需要在目标 CUDA 环境验证官方权重加载与一小批真实数据；CPU 检查不能替代这一步。
