# 训练与评估协议

## 数据与训练

Train1296、GTdev60、CDL Test500。归一化固定来自Train1296；标签为0/1/255。训练不读取Test records，不以测试结果选模型。两组均seed42；micro_batch=1、累积8、每轮162次更新，BF16，编码器激活检查点开启。空间增强同时变换影像、标签、观测支持及缓存可靠性目标。

|阶段|最少/最多轮|监督|停止规则|
|---|---:|---|---|
|A|3/10|普通CE，MoE不训练|GTdev连续3轮无实质改善|
|M|3/10|普通CE + qG监督MoE的BCE与结构正则|GTdev和固定Train探针excess-BCE均连续3轮无实质改善|
|C|8/30|q*加权CE + q*监督MoE的BCE与结构正则|GTdev连续6轮无实质改善|

GTdev实质改善要求mIoU严格大于历史监测最优加0.0002；固定探针改善阈值0.0001，恰好达到差值不计改善。M入口从Train中固定选择最多32个具有有效GMM目标的瓦片，固定软目标和掩码，以BCE减目标熵衡量拟合。它不是标签正确率；无有效探针时M不能早停，只能到上限。

各阶段满足最少轮数后才允许停止。A/M按达到最少轮数后的GTdev原始mIoU选择阶段最佳整模型交接；C不回退继续训练。阶段结束写明 `early_stopping` 或 `maximum_budget`，达到上限不代表收敛。两组规则相同，实际轮数可能不同，因此不是严格相同更新数的消融。

## 权重选择与CDL

1. 每组仅在C阶段按GTdev原始mIoU保存top3，完全同分保留更早轮次；排序不使用早停min_delta。
2. 两组训练均成功结束，核对来源、阶段历史、初始化、共同阶段增强轨迹、配置和源码锁。
3. 在读取CDL测试前，统一冻结全部六份权重SHA256。
4. 全部六份权重测试；每组GTdev rank1固定为主结果，rank2/3为次要结果。不能按CDL重排或更换主结果。
5. Native30m-v1：500瓦片，1959211个全局去重有效像元，CDL EPSG:5070原生30m网格，概率面积平均，固定阈值≥0.5，不使用农田掩码、不读取测试伪标签。

冻结的评估几何文件 `code/source_snapshot/evaluate_native30.py` SHA256：`52f7f409a54405b54fe0b46630740bc58a01442092898f524a03b8c0422dc7bc`。

本次CDL仍是历史复用Test500协议，不称全新盲测。没有自动断点恢复；已有run不允许覆盖。只修剪当前run自己的top3旧候选，保留last和A/M阶段最佳。
