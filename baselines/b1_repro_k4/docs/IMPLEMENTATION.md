# B1实现说明与已知限制

本仓库整理不修改历史核心训练算法。8个核心文件hash见frozen_core_hashes.json，并通过测试逐个核验。

## 实际作用路径

影像 → 冻结AgriFM encoder → NativeFPN decoder → 分类logits → 普通CE。

时序影像、DOY、观测支持和encoder上下文 → A4路由/专家 → 可靠性 → GMM/EMA辅助监督。

分类logits不读取可靠性输出。A阶段仅训练decoder；M/J同时训练可靠性分支。J配置没有启用残差，不能因阶段名称就解释为已做特征融合。

## 保留的历史行为

- 每个阶段重新创建AdamW，decoder动量在阶段切换时重置。
- 所有参数统一梯度裁剪，辅助分支可间接改变decoder梯度缩放。这不是已量化的专家分类收益。
- DataLoader没有独立shuffle Generator，未启用完全确定性算法，相同seed不保证跨代码/硬件逐位一致。
- M阶段首次会进行两次目标刷新，保留原行为以保持历史协议。
- 缺测key由Transformer mask处理，但后续stage pooling仍包括缺测query输出；修复应作为新实验版本。
- 当前版本FiLM参数永久冻结，但B1配置本来关闭FiLM；启用FiLM前需另行修复和验证。
- checkpoint含model/optimizer，但不含完整RNG、worker和target-bank状态，不能把加载权重当作精确续训。
- 某些模块虽被标记可训练，B1前向没有调用它们；参数计数不代表这些模块得到有效梯度。

## 数据与评估边界

预检可核验1296个训练影像的历史hash。当前归档没有原始伪标签、source_map及GTdev参考逐文件hash；路径/形状验证不足以证明这些数据字节身份一致。

GTdev是Derived85，CDL是Native30m-v1。历史多次查看CDL的结果属于历史比较，不应描述为全新的独立盲测。复现实验保持同一协议，不根据目标分数反向调整配置。

## 整理时的验证

原始预训练权重曾本地加载349个张量，目标参数覆盖100%。原有10项契约通过；本仓库保留9项与B1直接相关的契约，去掉旧多实验队列测试，并增加源码hash、划分及配置测试。当前测试状态见仓库交付记录；CI需实际运行后才有GitHub运行结果。

运行脚本与路径配置属于整理层，核心Python包名和字节保留。不要在复现分支静默修复上述算法问题后继续沿用原结果标签。
